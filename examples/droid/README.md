# pi05 DROID

This directory contains pi05 DROID evaluation and dataset conversion helpers.

- `main.py` runs the DROID evaluation client.
- `convert_droid_data_to_lerobot.py` converts custom DROID data for pi05 fine-tuning.
- `compute_droid_nonidle_ranges.py` prepares non-idle ranges for RLDS training.
- `README_train.md` documents full-DROID training with `pi05_full_droid_finetune`.

Use `pi05_droid` for inference and `pi05_droid_finetune` or `pi05_full_droid_finetune` for training.
