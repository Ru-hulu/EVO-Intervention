Qwen3.5 2B / 4B 单卡 A100 实测
完成时间：2026-10-13（Asia/Shanghai）
配置：同一张 GPU 2，BF16，关闭思考，贪心生成，最多 128 tokens；每模型预热 2 次、正式 5 次。
输入：18 张 640×480 图片，98 词 prompt；5,562 输入 tokens，其中 5,400 视觉 tokens。

以下为 5 次平均值，单位 ms：
阶段	2B	4B
读取并解码 18 张图片	227.610	215.464
图像预处理	218.669	228.914
Prompt 模板、分词和打包	29.342	36.710
CPU → GPU 数据传输	48.367	46.204
视觉编码器（不含合并投影）	272.577	271.370
视觉 token 合并与投影	1.636	1.751
语言模型 Prefill	133.843	310.942
首 token 输出头	0.728	0.903
其他调度与输入准备	26.507	27.009
首 token 之后的解码	4972.049	4184.480
输出转文本	0.349	0.389
端到端总计	5931.676	5324.137

附加指标：
2B：输出 84 tokens；端到端首 token 0.959s；后续解码 16.70 tokens/s；峰值 PyTorch allocated 4.98 GiB。
2B：模型加载 6.613s；处理器加载 4.408s；第一次预热 9.049s（均不计入稳态端到端）。
2B 完整回答：The robot first picks up the headphones from the desk, then places them back down on a stand. Next, it lifts the laptop and moves it to a new position on the desk. Finally, it closes the laptop and sets it upright on a black stand. The final state shows the headphones on a stand, the laptop closed and standing on a black base, and the bookshelf still holding its books.
4B：输出 53 tokens；端到端首 token 1.139s；后续解码 12.43 tokens/s；峰值 PyTorch allocated 9.52 GiB。
4B：模型加载 7.251s；处理器加载 4.197s；第一次预热 25.939s（均不计入稳态端到端）。
4B 完整回答：The robot manipulates a laptop, initially closing it on its stand and then moving it to a book stand. The final visible state shows the closed laptop resting on the book stand while other objects like headphones and a wooden box remain stationary on the table.

4B 本次完整回答更快，主要因为输出更短；其首 token 延迟更高，后续每 token 解码更慢。
视觉/投影/prefill/输出头使用 CUDA events；其余阶段使用 wall-clock；其他开销是首 token 时间减去非重叠 CUDA 分段并加输入准备。
没有用模拟值代替实测。原始每次结果见 results_2B.json、results_4B.json。
GPU 2 独占，但其余 GPU 的训练与评估仍在运行，CPU 和磁盘属于共享主机资源。
