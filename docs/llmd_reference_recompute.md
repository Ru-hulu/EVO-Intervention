# LLMD 论文标准与本次参考统计修正

本文是计算协议与审计记录；**不代表重新计算已经完成**。原有 640 帧参考统计生成的视频已撤回并删除，旧 CSV 仅保留作审计，不作为修正后的实验结果。

## 1. 论文原文如何定义 LLMD

依据本地论文原文 `VLA-FAIL/main.tex` 的 “Last-Layer Token-Wise Mahalanobis Distance” 和 `appendix.tex` 的 “Hyperparameters”。正文定义完整训练数据的经验统计；附录推荐正则化系数为 $10^{-6}$。相关章节未给出“每条轨迹抽 8 帧”之类的参考集抽样规则。

### 固定模型、预处理和噪声

首先冻结微调后的策略。在纯高斯噪声端点，用同一个噪声数组提取每个观测的特征：

$$z_{i,s}=f(o_i,t=0,a_0^*)_s,\qquad a_0^*\sim\mathcal N(0,I).$$

- $i$ 是训练集中的观测编号；$s$ 是动作块中的 token 位置。
- $z_{i,s}$ 来自动作专家最后的动作／速度场线性输出投影之前，不是 VLM 图像 token，也不是最终动作值。
- 噪声只抽取一次，拟合、校准、评估都复用同一个数组；不能每帧重新抽取。
- 论文将纯噪声端记为 $t=0$。本项目使用的 LeRobot pi05 实现从 $t=1$ 的纯噪声向 $t=0$ 去噪，两者是相反的时间参数化。应对齐“纯噪声端点”，不能照抄数值而取错端点。
- 正常动作采样可以继续使用自己的随机噪声。固定噪声的诊断分支不应改变原动作采样。

### 每个 token 独立计算均值和完整协方差

设微调训练集有 $N$ 个观测，每个特征有 $F$ 维：

$$\mu_s=\frac1N\sum_{i=1}^{N}z_{i,s},$$

$$\Sigma_s=\frac1N\sum_{i=1}^{N}(z_{i,s}-\mu_s)(z_{i,s}-\mu_s)^\top.$$

这是总体协方差，分母为 $N$。每个 token 各有一个 $F\times F$ 矩阵，不把所有 token 混成一个分布，也不只保留对角线。采用流式中心矩合并可以得到同一统计量，且无须把整个数据集的特征同时放入内存。

为保证数值可逆，使用：

$$\Sigma_s^\lambda=\Sigma_s+10^{-6}I.$$

附录将这项解释为确保可逆性的微小数值修正，不是用来调出成功／失败分离效果的可训练损失。

### 当前观测的分数

$$d_s^2=(z_s-\mu_s)^\top(\Sigma_s+10^{-6}I)^{-1}(z_s-\mu_s),$$

$$S_{\mathrm{LLMD}}=\max_{s=1,\ldots,H}d_s^2.$$

注意：使用距离平方、不取平方根；跨 token 取最大值、不取平均；论文不对 LLMD 做时间平滑。代码用 Cholesky 分解和三角求解实现同一公式，避免显式求逆。

LLMD 是相对于参考分布的异常程度，**不是失败概率**。阈值还需要独立成功校准轨迹，不能从这两条失败视频上挑阈值再宣称有效。

## 2. 旧结果的问题在哪里

旧参考集来自清洗后的示范集合前 8 条轨迹，每条均匀抽 80 帧，共 640 帧。当前实现每个 token 的特征维度为 1024。

中心化后协方差满足：

$$\operatorname{rank}(\Sigma_s)\leq\min(N-1,F)=639<1024.$$

所以至少 385 个方向在有限样本中没有估计到方差。若某方向的协方差特征值为 $\sigma_j$，该方向对距离的贡献为：

$$\frac{\langle z-\mu,u_j\rangle^2}{\sigma_j+10^{-6}}.$$

当 $\sigma_j=0$ 时，分母仅为 $10^{-6}$。正常但未覆盖的状态也可能得到很大的分数。这不能证明观察到的全部大分数都由秩不足造成，却足以说明旧参考统计不适合承担完整训练分布的基准。

另一个独立限制：旧视频使用 `pi05_piperx_insert_copper_screw_bs64_15k_oss` 离线重放；失败轨迹的采集策略是 `pi05_piperx_full558_h100_r13_step50000`。旧参考和旧评估使用同一个 15k 模型，因此并非不同模型的特征直接相减，但不能把结果解释为原采集策略当时的内部状态。

已核对的旧参考轨迹 0–7，其完整 state 数组与下载的 HF 数据对应轨迹一致。这说明它们有相同的数据来源证据，不能据此把旧参考描述成“混入失败数据”。主要缺陷是覆盖过小，以及评估模型与采集模型不同；图像是否逐像素一致不能仅由 state 一致推得。

## 4. 计算量与抽样的区别

4090B 的现有 FP32 单观测重放日志记录参考特征提取约 0.156 秒／帧。这是模型推理段的实测，不包括所有读图、统计和视频时间，也不是对其他检查点或批大小的速度保证。

| 范围 | 估计观测数 | 纯特征提取估计 | 总时间预算 |
|---|---:|---:|---:|
| 全部原始帧 | 1,255,729 | 54.4 小时 | 约 2.5–3 天 |
| 每条轨迹每秒一帧 | 约 4.2 万 | 约 1.8 小时 | 约 3–5 小时 |
| 每条参考轨迹均匀 8 帧 | 556 条时为 4,448 | 约 12 分钟 | 约 40–90 分钟 |

总时间是假设 GPU 持续可用的预算，网络传输、资源占用及更换模型会改变它；批处理优化也可能缩短时间。抽样仍使用论文的距离公式，但得到的是抽样经验分布，必须写作近似参考统计，不能称为全量遍历。样本数大于特征维度只消除了必然秩不足的计数条件，不保证矩阵良态或足够覆盖。

## 5. 四个视频应如何比较

四条轨迹应使用同一参考统计、同一模型、同一 ACC 参数和相同纵轴范围。报告完整轨迹统计与共同时间窗统计，避免成功示范较短而失败轨迹约 300 秒造成比较混淆。

ACC 对同一段未来时间的两次预测比较：

$$\hat S_t=\frac1{3(H-R)}\sum_{d=1}^3\sum_{i=1}^{H-R}\frac{|a^{t-1}_{R+i,d}-a^t_{i,d}|}{\max(\max_i a^t_{i,d}-\min_i a^t_{i,d},v_{\min})},$$

$$S_t=0.9S_{t-1}+0.1\hat S_t.$$

其中位置是绝对末端 XYZ；双臂应分别计算并注明如何汇总。论文实机设置 $v_{\min}=0.01$，仿真为 $0.001$。旧实机预览用的是 $0.001$；严格参照论文实机设置时需重新计算，不能仅替换 LLMD 而忽略这个区别。

按 1 Hz 查询、$\alpha=0.9$ 时，EMA 半衰期约为 $\log(0.5)/\log(0.9)=6.58$ 秒。平滑后的峰值时间不能直接视为物理故障发生时间。没有故障起点标注时，不能计算可信的提前预警时间。

最终分析应结合视频场景与具体时刻解释：LLMD 高是否伴随陌生观测；ACC 高来自绝对预测偏差变大，还是运动幅度变小导致归一化放大；两者低时是否仍发生静止、循环重试或语义错误。在新统计完成前不沿用旧分数得出性能结论。
