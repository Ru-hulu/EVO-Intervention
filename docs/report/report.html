进度标签核验结论

80 个视频、399 个 episode、262,525 帧完成独立重算，包含 140 次回滚。逐条检查远程实际保存的 199,453 条样本，未发现错误标签；保存值与重算值的误差不超过 5.1 × 10⁻⁹，来自八位小数舍入。

  1. 每次 subtask 尝试分别累计 delta，得到 SubtaskCon[S]；同一任务 ID 的 NormFact[id] 取最后一次执行的 delta 总和。
  2. 每帧贡献为 stepcon = delta[frame] × NormFact[nowid] / SubtaskCon[S]。同一 ID 的不同尝试具有相同的总贡献，不同 ID 的总贡献仍可不同。
  3. 段首根据 FailSet = (restid ∪ {nowid}) − PRE_R 扣除失效 ID 已累计的缩放贡献并清零；保留其他 ID 的贡献，再累加当前帧。
  4. 每个 episode 的整条曲线除以该 episode 最终累计值，保留进度回退。最后一次执行视为成功，由 JSON 标注保证。

示例：示范数据 file-005 / episode 4 在第 2094 帧发生回滚，进度由约 80.49% 降至 23.05%（帧编号从 0 开始，回滚后的值已包含当前帧贡献）。

生成索引时已计算完整逐帧进度数组，索引中的 target.progress 保存每个样本最后一帧的进度。本次索引生成没有另行导出完整逐帧进度文件。
